# Logo5 by SoulFlame

Работещ MVP за логопедична помощ за деца в Сливен, свързан със Supabase и Vercel.

## Продуктова идея

Logo5 е система за логопедичен кабинет, която комбинира:

- публична landing страница
- записване на дете
- услуги и цени
- родителски профил
- личен чат за конкретното дете
- библиотека с материали, снимки и видеа
- профил „За Веска“
- админ панел за записвания, съобщения и материали
- безопасен LOGO5 AI помощник с проверена база знания
- терапевтичен център: оценки, цели, сесии, документи и напредък
- Supabase модел с Row Level Security за родител и назначен логопед

## Бранд

**Logo5 by SoulFlame**

Logo5 означава 5 стъпки към ясна реч:

1. Оценка
2. План
3. Упражнения
4. Подкрепа
5. Напредък

## Технология

Проектът е бърз статичен single-file frontend в `index.html`, готов за Vercel. Публичните заявки за консултация се записват в `logo5_appointment_requests`. Клиничните таблици са с префикс `logo5_` и са защитени с RLS.

AI модулът в тази версия дава образователни насоки и ясно обозначава границите си. Той не поставя диагнози. Клиничната оценка и терапевтичните решения остават при квалифициран логопед.

## Deploy във Vercel

1. Vercel → Add New Project
2. Import GitHub repo: `SoulFlameAdmin/logo5`
3. Project name: `logo5`
4. Framework preset: Other
5. Deploy

След deployment адресът трябва да бъде:

`https://logo5.vercel.app`
